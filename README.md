## Course Description

This course focuses on solving computational problems that manipulate collected data by studying a core set of data abstractions, data structures, and algorithms that provide a foundation for writing efficient programs. Course content includes theoretical topics in algorithmic efficiency and complexity, abstract data types including graphs, trees, heaps, stacks, and priority queues, searching, hashing, and sorting algorithms implemented in C++.

## Course Objectives

The course aims to:

1. Provide a comprehensive understanding of analyzing algorithms and their computational complexity.

2. Enable the development of core data structures including Abstract Data Types (ADTs), Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming language.

3. Apply mathematical techniques to analyze the efficiency of various algorithms and standard operations on data structures.

4. Implement algorithms to conduct real-system performance measurements and analyses in C++.

5. Contribute towards the attainment of **SDG 9: Industry, Innovation, and Infrastructure**.
